# Lições

O que o escritório aprendeu com o uso. A Kioku propõe lições no resumo semanal (`out/semana/<data>/licoes_propostas.md`); só entram aqui depois de a equipa as aprovar.
Uma lição é um padrão que se repetiu pelo menos duas vezes, escrita de forma que um funcionário a possa aplicar.
